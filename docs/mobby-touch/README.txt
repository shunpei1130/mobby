モビー ぷにぷに体験・静的サイト版

【そのまま公開する方法】
dist フォルダの中身を、公式サイト内の任意のフォルダへアップロードしてください。
例: 公式サイト/mobby-touch/

アップロード後は次のようなURLで開けます。
https://あなたのドメイン/mobby-touch/

【既存ページ内へ埋め込む場合】
同じサイト内へアップロードした後、既存ページへ以下を追加してください。

<iframe
  src="/mobby-touch/"
  title="モビー ぷにぷに体験"
  style="width:100%;height:900px;border:0;border-radius:24px;"
  loading="lazy"
></iframe>

スマホでは高さを100svh前後に調整すると見やすくなります。

【収録キャラクター】
もびち・もびやん・ギャルモビー・病みモビー・ファクトマン

この静的版はサーバー機能を使用していません。
HTML・CSS・JavaScriptと同梱画像だけで動作します。
