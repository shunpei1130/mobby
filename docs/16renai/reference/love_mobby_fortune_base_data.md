# 恋愛モビー占い：基礎情報整理
## 目的
- 診断完了後の接触回数を増やす。
- 占いを「毎日キャラに会う理由」にする。
- 恋愛相性表は恋愛分野の判定として扱い、占いでは別概念の「キーパーソン」を使う。
- 共有導線は「このタイプの人が今日のキーパーソンかも。診断してみて」という形に寄せる。
## 既存素材から使う前提
- 16タイプとタイプ名。
- 各タイプのキャラ画像。
- タイプ別の肯定文・分かってる感。
- 共有カードの保存したくなるトーン。

## 表示上の注意
- 「相性がいい」は占い内では原則使わない。
- 代わりに「今日のキーパーソン」「助けてくれるかも」「流れを変えてくれるかも」「気づきをくれるかも」を使う。
- 恋愛対象に限定しない。友達、同僚、SNS上の知人、家族、まだ診断していない誰かも含められる。
- キーパーソン表示の直下に「このタイプかも？診断を送る」を置く。
