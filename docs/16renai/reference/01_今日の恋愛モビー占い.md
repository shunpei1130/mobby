# 01_今日の恋愛モビー占い

## 役割

「今日の恋愛モビー占い」は、恋愛モビーパスを毎日開く理由になるコンテンツ。  
診断結果の延長ではなく、ユーザーがその日に取れる小さな恋愛行動を示す。

ユーザーが知りたいのは、抽象的な運勢ではなく次のようなこと。

- 今日は連絡していい日か
- 押すべきか、待つべきか
- 返信が遅い相手をどう受け取るか
- どのくらい好意を見せていいか
- 今日は何をやると魅力が出るか
- 何をすると重く見えるか
- 今日のキーパーソンは誰か
- 買わずにできるラッキー行動は何か

日次占いは、朝・昼・夜どのタイミングでも読めるようにする。  
ただし、行動提案は「今日中にできること」に限定する。

## 無料版と有料版の差

### 無料版

無料版は短い一言まで。

```text
今日の恋愛テーマ：
焦らず、少しだけ余白を残す日
```

または、

```text
今日の恋愛運：★★★☆☆
今日は“確認”より“共有”が合う日。
```

### 有料版

有料版では以下を表示。

```text
今日の恋愛テーマ
今日のあなたの状態
今日やるといいこと
今日やめた方がいいこと
連絡・LINEのヒント
ラッキーアクション
ラッキーアイテム
キーパーソンになりそうなタイプ
今日の一言
```

```text
ありがとうを一回多く言う

相手の話を一つだけ覚えておく
自分から話題を一つだけ出す
```

## 重複回避ルール

日次占いは以下をログ化。

```text
userId
typeCode
date
theme
actionKeyword
luckyAction
luckyItem
keyPersonType
contactAdvice
avoidAdvice
messageHash
```

最低限の制御。

```text
過去7日以内に同じthemeを出さない
過去7日以内に同じluckyActionを出さない
過去7日以内に同じluckyItemを出さない
過去14日以内に同じkeyPersonTypeを連続させない
過去30日以内に同じ本文構成を繰り返さない
同じタイプでも全ユーザーに完全同文を出さない
「素直に」「大切に」だけで終わる汎用文を避ける
```

# 16タイプ別・日次占いの方向性

## HLTO：花束の主人公モビー

### 方向性

愛されたい気持ちや、ときめきを受け取る力が魅力。  
「愛されたい気持ちを否定しないこと」と「相手に求めすぎない伝え方」を中心にする。

### テーマ例

```text
愛されたい気持ちを素直に出す日
嬉しいを大きめに表現する日
確認ではなく喜びで伝える日
主役になりすぎず、相手にも光を当てる日
```

### ラッキー行動例

```text
嬉しかったことを短く伝える
ありがとうの後に一言だけ感想を足す
鏡を見て表情を整える
いつもより少し明るいリップにする
```

### サンプル

```md
# 今日の恋愛モビー占い

## 今日の恋愛テーマ
愛されたい気持ちを、確認ではなく喜びで出す日。

## 今日のあなたの状態
今日は、相手の反応をいつもより少し気にしやすい日です。
でも、それはあなたが重いからではなく、恋をちゃんと特別なものとして受け取りたいから。
その気持ちは悪いものではありません。

## 今日やるといいこと
「なんで返してくれないの？」より、「返ってきて嬉しい」の方が、あなたの魅力が自然に出ます。
求めるより、喜びを見せる。今日はその方が恋が進みやすいです。

## 今日やめた方がいいこと
相手の反応を試すような言い方。
少し寂しくても、遠回しに不機嫌を見せると、あなたの本当の可愛さが伝わりにくくなります。

## 連絡・LINEのヒント
送るなら、長く説明するより短く明るく。
「これ見て思い出した」くらいの軽さがちょうどいい日です。

## ラッキーアクション
いつもより少しだけ明るい表情で鏡を見る。

## ラッキーアイテム
普段使っているリップ。

## キーパーソンになりそうなタイプ
恋に旗を振る人モビー。

## 今日の一言
愛されたい気持ちは、隠すより可愛く見せた方が届きます。
```

## HLTC：秘密の星モビー

### 方向性

二人だけの世界や静かな特別感を大事にする。  
「言葉にしない深さ」と「相手が安心できる小さなサイン」のバランスを扱う。

### テーマ例

```text
静かに特別感を育てる日
言葉を少なくしても温度を残す日
二人だけの合図を大事にする日
見せない愛を少しだけ見せる日
```

### ラッキー行動例

```text
相手だけに伝わる一言を送る
既読を急がず、落ち着いて返す
スマホの待ち受けを夜空や落ち着いた写真にする
短いけれど温度のある言葉を選ぶ
```

### サンプル

```md
## 今日の恋愛テーマ
全部を見せずに、ひとつだけ温度を残す日。

## 今日のあなたの状態
今日は、気持ちを大きく出すより、静かに大事にしたい感覚が強まりそうです。
ただ、相手によってはその静けさを「距離を置かれている」と受け取ることがあります。

## 今日やるといいこと
長く説明するより、短くても特別感のある一言を置いてください。
「これ、あなたに言いたかった」くらいの小さなサインが効きます。

## 今日やめた方がいいこと
分かってくれるはず、と何も見せないこと。
あなたの深さは魅力ですが、少しだけ見せた方が相手も安心できます。

## 連絡・LINEのヒント
即レスにこだわらなくて大丈夫。
ただし、返す時は淡くしすぎず、最後に一言だけ温度を残すこと。

## ラッキーアクション
スマホの待ち受けを落ち着いた写真にする。

## ラッキーアイテム
メモアプリ。

## キーパーソンになりそうなタイプ
胸奥のロマンモビー。

## 今日の一言
秘密にしたい気持ちほど、少しだけ見せると特別になります。
```

## 品質チェック

```text
同じユーザーに同じラッキーアイテムが連続していないか
同じタイプに同じテーマが続いていないか
全タイプで本文構成が同じになっていないか
ラッキーアイテムが買わないと成立しないものになっていないか
ユーザーを責める文になっていないか
行動が現実的か
恋愛状態に合っているか
相手の気持ちを断定しすぎていないか
```
