# 06_状況別占い

## 役割

「状況別占い」は、ユーザーの現実の悩みに合わせて、占いの入口を増やすコンテンツ。  
恋愛は、タイプだけでは足りない。  
同じタイプでも、片思い中なのか、恋人がいるのか、復縁したいのか、曖昧な関係なのかで必要な言葉は違う。

状況別占いは、ユーザーが今の状態を選んで読む。  
「今の自分に関係ある」と感じやすく、サブスクの体感価値を上げやすい。

## 基本ルール

### 1. 相手の気持ちを断定しすぎない

避ける例。

```text
相手はあなたのことを好きです。
相手はもう冷めています。
復縁できる可能性が高いです。
```

望ましい例。

```text
相手の気持ちはまだ断定できません。
ただ、今は返信の速さだけで判断するより、会った時の態度や、話を続けようとする姿勢を見る方が現実的です。
```

### 2. ユーザーの感情を否定しない

避ける例。

```text
気にしすぎです。
重くならないようにしましょう。
依存しないようにしましょう。
```

望ましい例。

```text
気になってしまうのは自然です。
ただ、その不安のまま送ると、あなたの本当に伝えたいことが責める言葉に変わってしまうことがあります。
```

### 3. 3日以内の小さな行動を必ず入れる

良い例。

```text
相手が前に話していたことを一つだけ会話に出す
送る前に一度メモに本音を書く
次に会う予定について、自分の希望を一つだけ入れる
今日は相手のSNSを見ない夜を作る
```

## 片思い

```md
# 状況別占い：片思い

## 今の状況
相手の反応ひとつで気持ちが上下しやすい時期です。
まだ関係がはっきりしていないぶん、小さな会話や返信の温度を大きく受け取りやすくなっています。

## 今のあなたの心の状態
好きな気持ちがあるからこそ、自然に振る舞いたいのに不自然になったり、何気ない一言を何度も思い返したりしやすいです。
でも、それは恋に弱いからではありません。
まだ確かめられない関係だから、心が細かく反応しているだけです。

## 相手から見えやすいあなた
あなたのタイプによって見え方は変わります。

HL系なら、好意が表情や反応に出やすく、相手から見ても分かりやすい魅力になります。
HF系なら、軽やかに見えるぶん、本気度が伝わりにくいことがあります。
SL系なら、相手を支える姿が印象に残りますが、自分の好意を後回しにしやすいです。
SF系なら、自然な距離感で近づけますが、恋愛感情が薄く見えることがあります。

## 今、恋が動きやすいポイント
片思いでは、いきなり告白の空気を作るより、相手があなたと話す理由を増やすことが大切です。
恋愛の話題に持ち込む前に、
「話しやすい」
「一緒にいると楽」
「また話したい」
と思ってもらうこと。

## 今やらない方がいいこと
相手の反応を急に試すこと。
わざと冷たくすること。
返信速度だけで可能性を判断すること。

## 3日以内の小さなアクション
相手が話していたことを一つだけ覚えていて、自然に会話に出す。
たとえば、
「この前言ってたやつ、どうなった？」
くらいで十分です。

## 送るならこの一言
「この前話してたの思い出した」

## この状況で大切にしてほしいこと
片思いは、相手に好かれるために自分を削る時期ではありません。
相手との距離を見ながら、自分の魅力が一番自然に出る形を探す時期です。
```

```md
# 状況別占い：両思い直前

## 今の状況
お互いに好意がありそうなのに、まだはっきりとは言えない時期です。

期待していいのか、勘違いなのかを行き来しやすい状態です。
嬉しい瞬間があるほど、次に反応が薄い時に不安になります。

## 相手から見えやすいあなた
Hタイプは、嬉しさが出やすく、相手に好意が伝わりやすいです。
Sタイプは、相手に合わせられるぶん、好意より優しさに見える場合があります。
Lタイプは、近づきたい気持ちが出やすいです。
Fタイプは、軽やかに見えるため、相手が本気度を測りかねることがあります。

## 今、恋が動きやすいポイント
ここでは、強い告白より“次につながる一言”が効きます。
関係を急に決めるより、二人でいる理由を増やすこと。
次の予定、もう少し話す時間、また会いたい気持ちを小さく置くのがよいです。

## 今やらない方がいいこと
相手を試すために急に冷たくすること。
他の人の影を出して反応を見ようとすること。
好意を隠しすぎて、相手に脈なしだと思わせること。

## 3日以内の小さなアクション
「また話したい」「また行きたい」を軽く言う。
重くせず、でも次を作ること。

## 送るならこの一言
「今日の話、また続き聞きたい」

## この状況で大切にしてほしいこと
両思い直前の恋は、焦って壊すより、曖昧な好意を少しずつ確かにしていく方が進みやすいです。
```

```md
相手に正解を教えるイメージです。

## 送るならこの一言
「こうやって話せるの、けっこう嬉しい」

## この状況で大切にしてほしいこと
```

```md
## この状況で大切にしてほしいこと

大げさなことより、小さな感謝を見える形にすることで続きます。
```

## 曖昧な関係

```md
# 状況別占い：曖昧な関係

## 今の状況
近いようで、はっきりしない関係です。
連絡はある。
会うこともある。
でも、関係名がない。
その状態が長くなるほど、嬉しさと不安が同時に増えやすくなります。

## 今のあなたの心の状態
楽しい瞬間があるぶん、余計に苦しくなることがあります。
何もないなら諦められるのに、優しい時がある。
期待してしまう材料がある。
だから、簡単には離れられない。

その気持ちは自然です。
ただし、曖昧な関係では、相手の都合のいい距離に自分を置き続けないことが大切です。

## 相手から見えやすいあなた
Hタイプは、愛されたい気持ちが見えるぶん、相手にとって分かりやすい存在になります。
Sタイプは、相手を受け入れすぎて、都合のいい安心役になりやすいです。
Lタイプは、近さを求めるので曖昧さに疲れやすいです。
Fタイプは、自由に見えるぶん、相手にも曖昧さを許しているように見えることがあります。

## 今、恋が動きやすいポイント
今すぐ白黒をつけるより、まずは自分の中の最低ラインを決めること。
たとえば、
「会うならちゃんと予定を立てたい」
「夜だけの連絡は続けない」
「寂しい時だけ呼ばれる関係にはしない」
など。

## 今やらない方がいいこと
相手に合わせ続けること。
不安なのに平気なふりをすること。
関係を壊したくなくて、何も言わないこと。

## 3日以内の小さなアクション
次に会う、または連絡する時に、自分の希望を一つだけ入れる。
「今度はもう少し早い時間に会いたい」
「次はちゃんと予定決めたい」
このくらいでいいです。

## 送るならこの一言
「また話したいけど、次はちゃんと予定決めたいな」

## この状況で大切にしてほしいこと
曖昧な関係で一番大切なのは、相手の気持ちを読むことではなく、自分が雑に扱われていないかを見ることです。
```

# タイプ別差分の入れ方

## H/S差分

```text
Hタイプ：
愛されたい気持ち、反応を見たい気持ち、特別扱いされたい気持ちに触れる。

Sタイプ：
支えすぎる、相手に合わせすぎる、自分の希望を後回しにする点に触れる。
```

## L/F差分

```text
Lタイプ：
近さ、連絡頻度、会う頻度、安心したい気持ちに触れる。

Fタイプ：
自由、一人時間、重く見られたくない気持ち、本気度が伝わりにくい点に触れる。
```

## T/A差分

```text
Tタイプ：
ときめき、刺激、特別感、盛り上がりへの期待に触れる。

Aタイプ：
安心、信頼、日常の安定、急な変化への不安に触れる。
```

## O/C差分

```text
Oタイプ：
見せたい、残したい、言葉や共有で愛を感じる点に触れる。

Cタイプ：
二人だけの世界、外に見せすぎないこと、言葉にしない深さに触れる。
```
