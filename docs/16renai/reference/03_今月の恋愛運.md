# 03_今月の恋愛運

## 役割

「今月の恋愛運」は、月1で読み応えを作り、継続理由にする看板コンテンツ。  
日次は軽い。週次は感情整理。月次は、恋愛の流れを大きく見る。

月額380円の場合、毎月の更新コンテンツが弱いと継続されにくい。  
そのため今月の恋愛運は、月初に必ず読ませるコンテンツとして設計する。

---

## ユーザーに提供する価値

```text
今月の恋愛全体の流れがわかる
月初・月中・月末で動き方を変えられる
出会い、片思い、恋人、曖昧な関係ごとの見通しがわかる
チャンス時期と注意時期が見える
自分のタイプに合った恋の進め方がわかる
月額課金している実感がある
```

## 月次コンテンツの注意点

### 1. 「毎月ほぼ同じ」を避ける

避ける重複。

```text
毎月「焦らずゆっくり」が続く
毎月「素直に伝えて」が続く
毎月ラッキー行動が「深呼吸」になる
毎月注意点が「返信を気にしすぎない」になる
月初・月中・月末の流れが毎回同じ
```

### 2. 月内の変化を作る

例。

```text
月初：自分の状態を整える
月中：相手との接点を増やす
月末：関係の温度を確認する
```

または、

```text
月初：動きすぎない
月中：一言だけ踏み込む
月末：次の予定を作る
```

### 3. 4分岐は必須

```text
出会い運
片思い運
恋人運
曖昧な関係の進展運
```

# 月次サンプル

## HLAO：ひなたの愛され人

```md
# 今月の恋愛運：ひなたの愛され人

## 今月の恋愛テーマ
“普通の優しさ”が、ちゃんと特別になる月。

## 今月のあなたの恋愛モード
今月のあなたは、無理に目立ったり、強くアピールしたりするより、自然体でいるほど魅力が伝わりやすい流れに入ります。
派手な恋の進展というより、気づいたら距離が縮まっているような月です。

ただし、あなた自身は「これって進んでるのかな」「私って印象が薄いのかな」と感じやすいかもしれません。
でも今月は、分かりやすい刺激より、安心して話せる空気が恋を動かします。
あなたのやわらかさは、相手にとって思っている以上に残ります。

## 月初の流れ
月初は、相手の反応をよく見る時期です。
ここで焦って距離を縮めようとすると、あなたの良さが少し出にくくなります。
まずは、自然に会話できる状態を作ること。
挨拶、短い返信、相手の話を覚えていること。
こういう小さなことが効きます。

## 月中の流れ
月中は、少しだけ特別感を出すとよい時期です。
誰にでも優しいあなたですが、好きな人や大切な人には“あなたには少し違う”というサインが必要です。
大げさでなくて構いません。
「それ覚えてたよ」
「この前言ってたやつだよね」
「なんかあなたっぽいと思った」
このくらいの一言が、相手の中に残ります。

## 月末の流れ
月末は、関係の温度を確認する時期です。
ただし、確認の仕方は重くしないこと。
「私のことどう思ってる？」と迫るより、「最近話せるの嬉しい」くらいの言い方が合っています。

## 出会い運
出会いは、にぎやかな場所より、落ち着いて会話できる場にあります。
誰かの紹介、共通の趣味、日常の延長にある関係が発展しやすいです。

## 片思い運
片思い中の人は、相手の緊張をほどく役割を持てる月です。
無理に恋愛っぽくしようとしなくても、話しやすい人として印象が積み上がります。

## 恋人運
恋人がいる人は、安心感が強まる月。
ただし、慣れが出やすいので、いつもの優しさに一言だけ甘さを足すとよいです。

## 曖昧な関係の進展運
曖昧な関係は、急に白黒つけるより、相手があなたを失いたくないと感じる瞬間を作る方が進みます。
優しくしすぎて都合のいい存在にならないよう、自分の予定や気持ちも大切にしてください。

## 注意したいこと
“私なんて普通だから”と思いすぎること。
今月のあなたは、普通に見える優しさこそが強いです。

## 今月のチャンスアクション
相手が話したことを一つ覚えていて、自然に会話に出す。

## 今月相性が上がるタイプ
静かな港の相棒。
安心感のテンポが合いやすい月です。

## 今月のラッキー行動
朝、スマホを見る前に一口だけ水を飲む。
気持ちを急がせず、自分のペースを取り戻す合図になります。
```

## 今月相性が上がるタイプの出し方

月次では、「今月相性が上がるタイプ」を1〜3タイプ出す。

```text
本人タイプと基本相性がよいタイプ
今月のテーマと補完関係にあるタイプ
ユーザーに必要な行動を促してくれるタイプ
今月の注意点を和らげるタイプ
```

例。

```text
花束の主人公 × 今月テーマ「確認ではなく喜び」
相性が上がるタイプ：恋に旗を振る人
理由：あなたの嬉しい反応を受け取って、恋を明るく進めてくれるから。

秘密の星 × 今月テーマ「安心のサイン」
相性が上がるタイプ：胸奥のロマン
理由：静かな深さを急がず受け取ってくれるから。

陽だまりを分ける人 × 今月テーマ「受け取る愛」
相性が上がるタイプ：毛布をかける守り人
理由：あなたが与えるだけでなく、安心して甘えられる流れを作りやすいから。
```

## 今月のラッキー行動ルール

月次のラッキー行動は、日次より少し習慣寄りにする。  
ただし、買い物や大きな行動は避ける。

良い例。

```text
朝、スマホを見る前に水を一口飲む
週に一度、トーク履歴を見返さない夜を作る
相手への返信を送る前に、責めに見えないか確認する
寝る前に、今日自分がよくやったことを一つメモする
週末にスマホの待ち受けを明るい写真に変える
好きな曲を一曲決めて、恋で不安な時の切り替え曲にする
```

避ける例。

```text
新しい服を買う
花柄の傘を持つ
恋愛運アップのアクセサリーを買う
高いカフェに行く
毎日長文日記を書く
```
