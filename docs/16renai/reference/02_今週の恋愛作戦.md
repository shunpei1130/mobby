# 02_今週の恋愛作戦

## 役割

「今週の恋愛作戦」は、週1で読ませる長文コンテンツ。  
日次占いが「今日どうするか」なら、今週の恋愛作戦は「この一週間の恋の流れをどう乗るか」を示す。

日次よりも読み応えを持たせ、ユーザーに以下の感覚を与える。

```text
今の自分、ちゃんと見てもらえている感じ
この不安はおかしくないと思える感じ
今週どう動けばいいかがわかる感じ
恋で自分だけが空回りしているわけではないと思える感じ
相手を責める前に、自分の気持ちを整理できる感じ
```

## 文章トーン

### 避ける表現

```text
あなたはもっと素直になるべきです。
相手に依存しすぎないようにしましょう。
恋愛に振り回されないことが大切です。
ネガティブに考えるのはやめましょう。
重くならないように注意しましょう。
```

これらは説教に見える。  
恋愛で不安なユーザーには刺さらない。

### 望ましい表現

```text
今週のあなたは、相手の反応を見すぎるほど、自分の魅力を小さく感じやすいかもしれません。
でもそれは、弱いからではなく、ちゃんと大事にしたい相手がいるから。
だから今週は、気持ちを消すのではなく、出し方を少しだけ軽くしてみてください。
```

ポイント。

```text
不安を否定しない
ただし不安のまま動く危険は伝える
行動を小さくする
相手の気持ちを断定しすぎない
ユーザーを責めない
我慢だけを正解にしない
```

---

## 状態別に出し分ける

同じタイプでも、片思い、恋人あり、曖昧な関係では文面を変える。

### 片思い

```text
まだ関係が固まっていない時期なので、好意を全部ぶつけるより、「この人と話すと明るい気分になる」という印象を残すことが先です。
```

### 恋人あり

```text
相手に正解を求めるより、「それをしてくれると私は嬉しい」と伝える方が、二人の空気が明るくなります。
```

### 曖昧な関係

```text
関係名を決める前に、あなたが雑に扱われていないかを見ることが大切です。
```

# 16タイプ別・今週の恋愛作戦

## HLTO：花束の主人公モビー

### 重点テーマ

```text
愛されたい気持ちを、魅力として見せる
相手の反応を待ちすぎない
喜び上手になる
確認ではなく、嬉しさで関係を動かす
```

### 週次サンプル

```md
# 今週の恋愛作戦：花束の主人公モビー

## 今週のテーマ
愛されたい気持ちを、確認ではなく輝きに変える週。

## 今週のあなたに起きやすいこと
今週のあなたは、誰かの一言や返信の温度に、いつもより心が動きやすいかもしれません。
返事が少し遅いだけで「私ばかり好きなのかな」と感じたり、相手の態度が淡いだけで「もう前ほどじゃないのかな」と考えやすい週です。

でも、その不安はあなたが面倒な人だから出てくるものではありません。
あなたは恋を、ちゃんと特別なものとして受け取りたい人です。
だから、愛情が薄く見えたときに寂しくなるのは自然です。

## 恋が進みやすいポイント
今週は、相手に愛情を求めるより、愛情を受け取ったときの反応を大きめに見せる方がうまくいきます。
「嬉しい」「そう言ってくれて安心した」「それ好き」など、素直な反応があなたの魅力を強くします。

## すれ違いやすいポイント
試すような言い方は避けた方がよいです。
「どうせ忙しいよね」「別にいいけど」みたいな言葉は、本当は寂しいだけなのに、相手には責められているように届くことがあります。

## 片思いの人へ
相手を振り向かせようと頑張りすぎるより、あなたが楽しそうにしている姿を見せる方が効きます。
今週は、好意を隠すより、好意の手前にある“明るい関心”を見せるのが正解です。

## 恋人がいる人へ
愛されているかを確認したくなったら、まずは愛されて嬉しかった瞬間を一つ言葉にしてみてください。
「この前のあれ、嬉しかった」と伝えるだけで、相手はまた同じ方向に愛情を出しやすくなります。

## 曖昧な関係の人へ
今週は、関係名を急いで決めるより、あなたといると楽しいという印象を積み上げる方が進展しやすいです。
ただし、都合よく扱われている感じがあるなら、笑って流しすぎないこと。

## 今週のNG行動
返信速度だけで愛情を測ること。

## 今週の小さなミッション
嬉しかったことを一つ、素直に言葉にする。

## 今週の締めメッセージ
あなたは、愛されたい人である前に、愛されたときに恋を美しくできる人です。
```

## HLTC：秘密の星モビー

### 重点テーマ

```text
二人だけの特別感を守る
言葉にしなさすぎて不安にさせない
静かな好意を小さく見せる
深さを守りながら、安心のサインを置く
```

### 週次サンプル

```md
# 今週の恋愛作戦：秘密の星モビー

## 今週のテーマ
見せない愛を、ひとつだけ見える形にする週。

## 今週のあなたに起きやすいこと
今週のあなたは、気持ちをあまり外に出さず、静かに大事にしたくなりそうです。
恋が進んでいるかどうかを、派手な出来事ではなく、二人だけの空気や小さな変化で感じ取りやすい時期です。

ただ、あなたが静かに大切にしているものは、相手から見ると少し分かりにくいことがあります。
距離を置いているつもりはなくても、相手が「嫌われたのかな」と感じる場合があります。

## 恋が進みやすいポイント
今週は、全部を言葉にする必要はありません。
ただし、ひとつだけ“あなたにだけ”と伝わるサインを置くと、関係が柔らかく進みます。
「これ、あなたに言おうと思ってた」
「なんとなく思い出した」
このくらいで十分です。

## すれ違いやすいポイント
何も言わなくても伝わるはず、と思いすぎること。
あなたの愛情は深いですが、相手が同じ深さで読み取れるとは限りません。

## 片思いの人へ
大きく好意を出すより、二人だけの共通点を一つ作るとよい週です。
秘密っぽい会話、小さな約束、相手だけに見せる反応が印象に残ります。

## 恋人がいる人へ
恋人には、安心の言葉を一つ置いてください。
長い説明はいりません。
「ちゃんと大事だよ」のような短い言葉が、今週は効きます。

## 曖昧な関係の人へ
曖昧な関係であなたが黙り続けると、相手も曖昧なままでいいと思いやすいです。
今週は、重く迫るのではなく、自分が大切にされたいラインを静かに見せること。

## 今週のNG行動
本当は気にしているのに、何も気にしていないふりをし続けること。

## 今週の小さなミッション
相手だけに向けた一言を送る。

## 今週の締めメッセージ
あなたの静かな愛は、少し見せたときにいちばん深く届きます。
```

## HLAO：ひなたの愛され人モビー

### 重点テーマ

```text
自然体の優しさが恋を進める
普通すぎるという不安を手放す
安心感に少しだけ特別感を足す
相手にとって居心地のいい存在になる
```

### 文面方針

「特別なことをしないと愛されない」という不安をほどく。  
ただし、安心感だけで終わると恋愛感が薄くなるので、好きな人には少しだけ特別扱いを見せるようにする。

## 週次コンテンツの重複管理

```text
同じタイプに同じ週テーマを2ヶ月以内に出さない
片思い・恋人あり・曖昧の本文を同じ構造にしない
NG行動を毎週「返信を気にしすぎる」にしない
ミッションを毎週「ありがとうを言う」にしない
締めメッセージはタイプ固有の魅力に紐づける
```
