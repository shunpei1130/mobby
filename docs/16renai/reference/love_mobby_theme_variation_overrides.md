# 実装時の注意

以下の条件を満たすようにしてください。

```text
各タイプ31日分の「今日のテーマ」がある
同一タイプ内で31日分のテーマが重複しない
別タイプ間でも完全一致するテーマ名を極力避ける
同じ意味でもキャラごとの語彙・比喩・温度に変換されている
「〇〇の日」だけに偏らない
月間テーマが16タイプそれぞれ違う構文・違う語感になっている
キャラ名だけ差し替えて成立するテーマになっていない
```

# 受け入れ条件

以下を追加の受け入れ条件にしてください。

```text
日次占いの「今日のテーマ」が全タイプで固有化されている
同一タイプ内で31日分の「今日のテーマ」が重複しない
16タイプ間で「今日のテーマ」の完全一致が大量発生していない
月間占いの「今月のテーマ」が16タイプそれぞれ固有化されている
月間テーマがテンプレート文に見えない
テーマだけを読んでもキャラの方向性が伝わる
```
