# 05_相手タイプ別攻略

## 役割

「相手タイプ別攻略」は、好きな人のタイプがわかった後に何度も見られるコンテンツ。  
占いというより、恋愛の取り扱い説明書に近い。

ただし「攻略」という言い方は内部向け。ユーザー画面では、少し柔らかくする。

表示名候補。

```text
あの人への接し方
あの人が嬉しい恋の進め方
あの人に届く愛情表現
あの人と距離を縮めるヒント
あの人の恋愛説明書
```

## 注意点

### 操作ではなく理解にする

避ける表現。

```text
こうすれば落とせる
相手を沼らせるには
このタイプはこう扱えばいい
相手を不安にさせると追ってくる
```

望ましい表現。

```text
このタイプは、急に踏み込まれるより、安心できる合図があると心を開きやすいです。
相手のペースを尊重しながら、あなたの気持ちも小さく見せていくのが合っています。
```
