# 各タイプ向けアドバイス

## 1. 透明感モデルモビィ

**特徴**  
日々のケアを丁寧に重ねて、近くで見るほどきれいな透明感を育てるタイプ。
派手に変えるより、保湿・髪のツヤ・姿勢・生活リズムなど、細部を整えることでモデルのような清潔感が増す。

### 三宅裕子さんからの Beauty Note

> 無理に大きく変えなくても、あなたの透明感は毎日の小さな積み重ねでちゃんと育ちます。  
> 今日は保湿、髪のツヤ、姿勢のどれか一つだけ丁寧にしてみて。  
> 韓国コスメを足すなら、主張が強いものより“肌を落ち着かせるもの”から選ぶのがおすすめです。

### 合う追加要素

- おすすめテーマ：鎮静ケア / 保湿 / トーンアップ下地
- CTA：三宅裕子さんの「毎日ケア投稿を見る」
- 商品導線：デイリー使いできる韓国スキンケア

### カード用一言

> 透明感は、毎日の細部から育つ。

## 2. 美容エディターモビィ

**特徴**

押しつけず、相手に合いそうな形で美容を編集してすすめられる。

### 三宅裕子さんからの Beauty Note

> あなたのおすすめは、押しつけ感がなくて人に届きやすいのが魅力です。  
> だからこそ、紹介するときは「これ良かった」だけじゃなくて、「どんな人に合いそうか」まで添えてみて。  
> やさしい言葉に、あなた自身の実感が乗ると、もっと信頼されるレコメンドになります。

### 合う追加要素

- おすすめテーマ：友達にすすめやすいコスメ / 初心者向け韓国コスメ
- CTA：三宅裕子さんの「愛用品紹介を見る」
- 商品導線：プチギフト / 万人受けスキンケア / リップ / パック

### カード用一言

> やさしいおすすめは、ちゃんと届く。
