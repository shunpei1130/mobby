# 日向葵衣から各タイプへのアドバイス

---

## 1. ひとま｜リラックス透明感タイプ

### 日向葵衣からのアドバイス

あなたは、無理に目立とうとしなくても、静かな空気そのものが魅力になる人だと思います。  
だから、美容も「盛る」より「整える」を大切にしてみてください。

肌は保湿を丁寧に、色は白・淡いピンク・水色みたいなやわらかいトーンが似合いそう。  
少しだけツヤを足すと、控えめなまま印象に残る透明感が出ます。

頑張りすぎた日は、早く寝ることもちゃんと美容です。  
猫みたいに丸まって休む時間を、自分に許してあげてね。

### 追加で入れるなら

**おすすめ行動：**  
「今日は何もしない美容の日」をつくる。

**結果画面の一言：**  
静かなまま、ちゃんと可愛い。あなたの透明感は、急がないところから生まれます。

## 2. ひとし｜癒しシェアタイプ

### 日向葵衣からのアドバイス

あなたは、自分が癒されたものを、誰かにもそっと渡せる人。  
そのやさしさは、すごく素敵な魅力です。

でも、みんなを癒そうとしすぎて、自分が疲れていないかだけは気にしてあげてください。  
「誰かに届ける前に、まず自分がほっとしているか」を確認すると、あなたの言葉や雰囲気がもっとやわらかくなります。

美容では、香り・保湿・ふわっとした質感が相性よさそう。  
お気に入りのリップやハンドクリームを「これよかったよ」と共有するだけでも、あなたらしい可愛さが出ます。

### 追加で入れるなら

**おすすめ行動：**  
お気に入りの癒しアイテムを1つ、ストーリーや友達に共有する。

**結果画面の一言：**  
あなたのやさしさは、誰かの今日を少し軽くする力があります。

## 3. ひぐま｜うるおいマイペースタイプ

### 日向葵衣からのアドバイス

あなたは、自分のリズムで少しずつ綺麗になっていくタイプ。  
一気に変わろうとしなくて大丈夫です。

毎日のスキンケア、湯船につかる時間、温かい飲み物を飲む時間。  
そういう小さな習慣が、あなたのうるおい感や安心感をつくってくれると思います。

ただ、マイペースでいるほど、周りには魅力が伝わりにくい時もあります。  
血色感のあるチークや、髪のツヤを少し足すだけで「元気そう」「雰囲気いいね」と伝わりやすくなります。

### 追加で入れるなら

**おすすめ行動：**  
夜の保湿ルーティンを固定する。

**結果画面の一言：**  
あなたの可愛さは、誰かに急かされない場所でゆっくり育ちます。

## 4. ひぐし｜やさしさグロウタイプ

### 日向葵衣からのアドバイス

あなたは、親しみやすさと華やかさのバランスがとても上手な人。  
明るいけど強すぎない、近づきやすい可愛さがあります。

美容では、ツヤ肌・血色感・やわらかいピンク系が似合いそう。  
ただし、全部を光らせるより、肌かリップか目元のどこか一つを主役にすると、あなたのやさしさが残ったまま綺麗に見えます。

みんなを明るくしたい気持ちがある人ほど、疲れていても笑ってしまうことがあります。  
無理な日は、ちゃんとオフの顔でいて大丈夫です。

### 追加で入れるなら

**おすすめ行動：**  
ツヤを足す日は、服や小物を少しシンプルにする。

**結果画面の一言：**  
あなたは、場を明るくするけど、まぶしすぎない。そこがいちばん魅力です。

## 5. きとま｜ときめき透明感タイプ

### 日向葵衣からのアドバイス

あなたは、透明感の中に小さなときめきを入れるのが似合う人。  
派手にしなくても、ひとつだけ光るポイントがあるとすごく魅力的に見えます。

メイクなら、ラメを一点だけ。  
服なら、淡い色の中に小物で少しだけアクセント。  
「全部可愛くする」より「ここだけ可愛い」を決めると、あなたらしい繊細さが残ります。

迷った日は、ベースを透明感に戻してみてください。  
そこに小さなきらめきを乗せるだけで、ちゃんと今日の気分が出ます。

### 追加で入れるなら

**おすすめ行動：**  
今日の主役ポイントを1つだけ決める。

**結果画面の一言：**  
あなたのときめきは、大きな光じゃなくて、近くで気づく小さな輝きです。

## 6. きとし｜きらめき共感タイプ

### 日向葵衣からのアドバイス

あなたは「これ可愛い！」を周りに広げるのが上手なタイプ。  
自分がときめいたものを、友達やファンと一緒に楽しめるところが魅力です。

新しいコスメ、可愛い写真、似合った服。  
そういうものを発信すると、あなたの明るさがちゃんと伝わります。

ただ、反応を気にしすぎると、自分が本当に好きなものが見えにくくなることもあります。  
投稿する前に「これは私が本当に好き？」と一回だけ聞いてみてください。  
好きがちゃんとある発信は、見ている人にも伝わります。

### 追加で入れるなら

**おすすめ行動：**  
「今日のかわいいポイント」を写真に残す。

**結果画面の一言：**  
あなたの“可愛い”は、ひとりで終わらず、誰かの真似したい気持ちになります。

## 7. きぐま｜自分磨きグロウタイプ

### 日向葵衣からのアドバイス

あなたは、ちゃんと自分を磨ける人。  
誰かに見せるためだけじゃなく、自分が納得したいから綺麗になろうとするところが素敵です。

美容では、鏡を見る時間を責める時間にしないこと。  
「ここが足りない」より、「昨日よりここが整った」を見つけてあげてください。

ツヤ系のスキンケアや、温まる習慣が相性よさそうです。  
頑張る日ほど、最後に湯船やストレッチみたいな休む時間を入れると、内側からのグロウ感が出ます。

### 追加で入れるなら

**おすすめ行動：**  
自分磨きの記録を写真やメモで残す。

**結果画面の一言：**  
あなたは、誰かに急かされなくても、自分の光を育てていける人です。

## 8. きぐし｜ステージビューティタイプ

### 日向葵衣からのアドバイス

あなたは、見られる瞬間をちゃんと楽しめる人。  
撮影、イベント、SNS、誰かに届く場面で、自分の魅力を出すのが上手です。

メイクは、ツヤ・血色・目元の印象を少し強めても似合いそう。  
「今日は見られる日」と決めたら、服や髪まで含めて一つのムードにすると、あなたの華やかさがより伝わります。

でも、ずっとオンでいる必要はありません。  
輝く人ほど、ちゃんと休む時間が必要です。  
ステージの外では、猫みたいに力を抜いてください。

### 追加で入れるなら

**おすすめ行動：**  
撮影やお出かけの日は、帰宅後の癒しルーティンまで予定に入れる。

**結果画面の一言：**  
あなたは、光を浴びるだけじゃなく、その場の空気ごと明るくできる人です。

# 結果画面に追加するならおすすめの欄

今の診断結果には、すでに以下のような項目があります。

- 似合うムード
- しんどい時
- 周りから
- 今日の美容ヒント
- 強み
- 気をつけたいこと

そこに追加するなら、以下が相性いいです。

| 追加欄 | 内容 |
|---|---|
| 日向葵衣からの一言 | コラボ感・本人感が一番出る |
| 今日の小さな美容ミッション | ユーザーがすぐ行動できる |
| あなたに似合う写真の撮り方 | SNS共有につながる |
| おすすめモチーフ | 猫、温泉、花、ミラー、スマホなどをタイプ別に出せる |
| シェア用一言 | X・Instagram共有時の文面に使える |

特に入れるべきなのは、**「日向葵衣からの一言」＋「今日の小さな美容ミッション」** です。

診断結果を読んで終わりではなく、  
「今日これやってみよう」と思えるので、満足度が上がります。
