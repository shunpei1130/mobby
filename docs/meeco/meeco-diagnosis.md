# meeco様向け「魔女の空想コスメ タイプ診断」ラフ

## 企画意図

- 『魔女の空想コスメ』の世界観を、Mobbyの参加型診断として体験化する確認用プレビュー。
- 診断結果は8タイプ。メール添付PDFで共有された8カットを、それぞれ結果ビジュアルとして使用。
- 関連リンクはイースト・プレス公式サイトと作品ページを掲載。
- コピーライト表記は、出版社様・権利元様から指定された正式文言へ差し替え予定。

## 診断設計

3軸で20問に回答し、8タイプへ分類します。

- ときめきの温度: ひらめき / 余韻
- 魔法の置き場所: 空想 / お守り
- 好きの届け方: ひとりで味わう / 誰かに贈る
