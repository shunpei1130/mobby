# meeco様向け「『魔女の空想コスメ』キャラタイプ診断」実装仕様

## 企画意図

- 『魔女の空想コスメ』の世界観を、Mobbyの参加型診断として体験化するコラボ企画。
- 診断結果は8タイプ。メール添付PDFで共有された8カットを、それぞれ結果ビジュアルとして使用。
- 関連リンクはイースト・プレス公式サイトと作品ページを掲載。
- コピーライト表記「『魔女の空想コスメ』©meeco／イースト・プレス」を各画面共通のフッターへ掲載する。

## 診断設計

3軸で20問に回答し、8タイプへ分類します。

- ときめきの温度: ひらめき / 余韻
- 魔法の置き場所: 空想 / お守り
- 好きの届け方: ひとりで味わう / 誰かに贈る

## 8タイプ

1. 海色きらめき人魚
2. 恋する赤ずきん
3. 夢見る花嫁
4. 双子の薔薇の精
5. 空想の魔女
6. 穏やかな妖精
7. 月の女王
8. 元気いっぱいな妖精
