# Mobby（モビー）

**Mobby（モビー）** は、思い出を撮影できる**カメラ型キーホルダー**の公式サイトです。
かわいいデザインで持ち歩けるミニカメラアクセサリーを紹介し、ユーザーが自分のタイプを楽しく診断できる無料ツールを提供しています。

🌐 公式サイト: [https://mobby.online/](https://mobby.online/)

---

## このプロジェクトでできること

### 📷 製品紹介
- Mobby（カメラ型キーホルダー）の紹介・購入予約ページ
- カラーバリエーション（ブルー・オレンジ・ピンク・パープル・イエローなど）の展示

### 🔍 モビー診断シリーズ（無料・40問）

各診断は40問の質問に答えると、あなたのタイプを16種類から分析して教えてくれます。

| 診断名 | URL | 内容 |
|---|---|---|
| **学校モビー診断** | `/16school/` | 学校でのキャラ・性格タイプを16タイプで診断（陽キャラ/陰キャラ、やんちゃ/真面目など） |
| **推し活モビー診断** | `/16stan/` | 推し活スタイルを16タイプで診断（現場派/在宅派、発信派/静観派など） |
| **メンヘラモビー診断** | `/16love/` | 恋愛・メンヘラ度を16タイプで診断（既読スルー耐性・恋の依存度・匂わせ度など） |
| **夜職モビー診断** | `/16night/` | 向いている夜職タイプを16種類で診断（キャバクラ・ガールズバー・ラウンジなど） |

### 📄 その他のページ
- プライバシーポリシー (`/privacy.html`)
- 利用規約 (`/terms.html`)
- 特定商取引法に基づく表記 (`/tokusho.html`)
- 会社情報 (`/company.html`)
- キャンペーン (`/win.html`)
